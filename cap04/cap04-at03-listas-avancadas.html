3. Glossário de Termos Técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
Define elementos como títulos, parágrafos, tabelas e formulários.
CSS
Linguagem utilizada para estilizar páginas HTML.
Permite controlar cores, fontes, layouts e responsividade.
JavaScript
JS
Linguagem de programação utilizada para adicionar interatividade às páginas web.
DOM
Document Object Model
Estrutura em árvore que representa os elementos HTML de uma página.
API
Interface que permite comunicação entre diferentes sistemas.
HTTP
Protocolo utilizado para transferência de dados na web.
URL
Endereço utilizado para localizar recursos na internet.
DNS
Sistema responsável por converter nomes de domínio em endereços IP.
